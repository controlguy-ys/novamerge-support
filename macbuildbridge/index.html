선택한 메타데이터를 이 Mac에서 확인합니다

  • 파일이나 폴더를 사용자가 직접 선택합니다. 앱은 선택한 원본에 쓰지 않습니다.
  • 가져온 파일의 지원 필드와 폴더 연결 정보는 앱의 로컬 저장소에 보관합니다.
  • 선택한 AI 메타데이터를 개발자 서버로 전송하지 않습니다.
  • 계정 로그인이나 API 키 입력이 필요하지 않습니다.

도움이 필요하신가요?

설정, 파일 가져오기, 오류 또는 개인정보 관련 문의는 아래 이메일로 보내 주세요.

support@slop-games.com

앱 이름, 앱·macOS 버전, 문제가 발생한 단계와 오류 문구를 함께 알려 주시면 도움이 됩니다. 공유 전 스크린샷이나 오류 문구에 개인 정보가 있는지 확인해 주세요.

처음 연결하기

  1. JSON 파일 가져오기로 버전 1 집계 JSON의 사본을 가져오거나, 데이터 폴더 연결로 서비스별 JSON이 있는 폴더를 선택합니다.
  2. 폴더의 파일 이름은 <provider-id>.json이어야 하며, 파일 안의 provider.id와 일치해야 합니다. 폴더 바로 아래의 파일만 읽습니다.
  3. 데이터 소스를 다시 읽으려면 새로 고침을 사용합니다. 폴더는 조회 후 15초 간격으로 확인합니다.

파일당 최대 1 MiB, 서비스당 세션 500개·한도 창 32개, 폴더와 가져온 서비스는 각각 최대 64개입니다. 서비스의 원본 API 응답이 아니라 지원되는 집계 JSON 형식이 필요합니다.

사용량이나 활동이 보이지 않을 때

데이터 소스의 관측 시각과 파일 형식을 확인해 주세요. 앱은 제공되지 않은 한도나 토큰을 0으로 만들지 않습니다. 오래된 활동은 상태 미확인으로, 오래된 사용량은 지난 데이터로 표시합니다. 샘플 화면에는 항상 샘플임을 표시하며 실제 계정 데이터와 섞지 않습니다.

개인정보처리방침

1. 앱이 읽는 데이터

사용자가 파일 선택 창에서 지정한 JSON 또는 폴더의 집계 메타데이터를 읽습니다. 지원되는 필드에는 서비스 이름·출처·관측 시각·사용 한도·토큰 수·추정 비용, 세션과 에이전트의 식별자·이름·역할·상태, 모델과 프로젝트 경로 등이 포함됩니다. 이러한 식별자와 경로도 개인 정보가 될 수 있습니다.

앱은 다른 앱의 계정 저장소, 프로세스 목록, 대화 기록을 자동으로 검색하지 않습니다. 대화 본문, 비밀번호, 인증 토큰 또는 API 키를 데이터 파일이나 지원 문의에 넣지 마세요. JSON 형식 검증이 모든 비밀값을 찾아 삭제하는 기능은 아닙니다.

2. 파일 가져오기와 로컬 사본

JSON 파일 가져오기는 지원 필드만 정규화한 사본을 이 Mac의 앱 컨테이너에 저장합니다. 지원되지 않는 JSON 필드는 사본에서 제외합니다. 원본 파일은 수정하지 않으며, 원본의 변경 사항이 사본에 자동으로 반영되지는 않습니다. 같은 서비스 파일을 다시 가져오면 기존 사본을 교체합니다.

3. 폴더 연결과 접근 권한

데이터 폴더 연결은 선택한 폴더의 JSON을 읽기 전용으로 확인합니다. 앱을 다시 열었을 때 연결을 복원할 수 있도록 macOS의 읽기 전용 보안 북마크를 앱 컨테이너에 저장합니다. 북마크에는 선택한 위치를 식별하는 정보가 포함됩니다. 조회가 끝나면 해당 보안 범위 접근을 해제합니다.

폴더에서 읽은 데이터는 화면을 보여 주는 동안 메모리에 보관할 수 있습니다. 조회가 실패하면 마지막으로 읽은 데이터와 오류 상태를 표시할 수 있으며, 오래된 활동의 유효 시간을 계속 적용합니다. 폴더 연결을 해제하면 저장한 북마크를 삭제하고 해당 소스를 더 이상 조회하지 않습니다.

4. 개발자에게 전송되는 정보

이 버전의 앱에는 자동 네트워크 수집, 분석 또는 추적 기능이 없습니다. 선택한 AI 메타데이터나 북마크를 개발자 서버로 전송하지 않습니다. macOS와 App Store 자체의 진단·구입 정보 처리는 Apple의 설정과 정책에 따릅니다. 운영체제 설정에 따라 로컬 데이터가 백업에 포함될 수 있습니다.

5. 지원 문의

직접 이메일을 보내면 이메일 주소와 사용자가 제공한 내용을 문의 답변과 문제 해결을 위해 처리합니다. 이메일 문의는 지원 메일함에 보관될 수 있습니다. 문의 내용 삭제를 요청하려면 같은 지원 이메일로 연락해 주세요. 개발자는 이 Mac에 저장된 앱 사본이나 선택한 원본 파일을 원격으로 삭제할 수 없습니다.

6. 이 지원 페이지

이 페이지는 외부 분석 스크립트나 외부 글꼴을 불러오지 않는 정적 페이지입니다. 웹 호스팅 서비스는 페이지 제공 과정에서 일반적인 접속 기록을 처리할 수 있습니다. 이메일 문의는 사용자가 메일 앱에서 직접 보내는 경우에만 전달됩니다.

7. 변경과 문의

앱의 데이터 처리 방식이 바뀌면 이 페이지와 최종 수정일을 갱신합니다. 이 방침에 대한 질문은 support@slop-games.com으로 보내 주세요.

데이터 삭제와 연결 해제

  • 가져온 사본 삭제: 앱의 데이터 소스를 열고, 가져온 파일 · 앱 내부 사본에서 해당 서비스의 삭제를 누릅니다.
  • 폴더 접근 해제: 같은 화면의 연결된 폴더 · 읽기 전용에서 연결 해제를 누릅니다. 저장된 북마크가 삭제됩니다.
  • 원본과 백업: 위 동작은 사용자가 선택한 외부 원본 파일을 삭제하지 않습니다. 원본과 백업 사본은 해당 위치나 백업 설정에서 관리하세요.

사본과 폴더에 같은 서비스가 있으면 한 소스를 지운 뒤 다른 소스의 데이터가 계속 표시될 수 있습니다. 해당 서비스의 조회를 모두 중단하려면 두 소스를 각각 확인하세요.

Support and privacy policy

Scope: the Mac App Store edition of MacBuildBridge for macOS. Last updated: September 12, 2026.

MacBuildBridge displays AI service usage, agents and sessions from aggregate JSON metadata that you select. Contact support@slop-games.com for app support or privacy questions.

Data you choose

The app reads a JSON file or the service JSON files directly inside a folder chosen in the file picker. Supported metadata may include service names, sources and observation times, usage limits, token counts, estimated costs, session and agent identifiers, names, roles and states, models and project paths. Identifiers and paths may contain personal information.

The app does not automatically search other apps' account stores, processes or conversations. It requires no account sign-in or API key. Do not put conversation content, passwords, authentication tokens or API keys in data files or support messages. Format validation is not a guarantee that every secret is detected and removed.

Local copies and folder access

Import JSON stores a normalized copy of supported fields in the app's container on this Mac. Unsupported JSON fields are discarded. The original file is not changed. Changes to the original are not applied automatically; importing the same provider again replaces its local copy.

Connect a data folder reads its provider JSON files without writing to that folder, checking again 15 seconds after each refresh. A read-only macOS security-scoped bookmark is stored in the app container to restore your selection after relaunch. The bookmark contains information identifying the selected location. The app releases scoped access after each read. Folder observations can remain in memory while displayed; a failed read may show the last observation with an error state.

Each JSON file must be no larger than 1 MiB, with at most 500 sessions and 32 usage windows per provider. Up to 64 provider files in a selected folder and 64 imported providers are supported. Folder filenames must match <provider-id>.json. Unsupported or stale values are not presented as verified live usage. Samples are always labeled and are kept separate from your selected data.

Transmission, support and this page

This version has no automatic network collection, analytics or tracking. It does not send selected AI metadata or bookmarks to a developer server. macOS and App Store diagnostics and purchase information are governed by Apple's settings and policies. Local data may be included in operating-system backups, depending on your settings.

If you email support, your email address and the information you send are used to answer the request and resolve the issue. Support correspondence may remain in the support mailbox. You may request deletion of support correspondence by email. The developer cannot remotely delete files on your Mac.

This static support page does not load external analytics scripts or fonts. The hosting provider may process ordinary access logs when serving the page. Email is sent only when you choose to send it through your mail application.

Delete a copy or disconnect a folder

Open Data Sources (데이터 소스). Under imported files, use Delete (삭제) for the provider's copy. Under the connected read-only folder, use Disconnect (연결 해제) to delete its bookmark and stop reading that source. These actions do not change or delete the external originals. Manage original files and backups at their respective locations. If the same provider is present in both sources, review both to stop displaying that provider.

We will update this policy and its revision date when the app's data practices change. For privacy questions, contact support@slop-games.com.

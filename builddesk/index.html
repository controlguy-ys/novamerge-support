BuildDesk 전체 제어판 개인정보 및 데이터 보관 안내

적용일: 2026-09-21. Windows BuildDesk 및 Mac 직접 배포 호스트에 적용합니다. AI 사용량 JSON을 조회하는 별도 Mac App Store 앱의 안내와 구분됩니다.

연결 및 권한

등록한 Windows와 Mac은 호스트 키를 확인하는 SSH 연결로 통신합니다. 같은 네트워크나 사용자가 설정한 Tailscale 연결이 필요합니다. 개발사의 중계 서버에 화면이나 프로젝트를 업로드하지 않습니다. Tailscale·Apple·Microsoft 등의 서비스에는 각각의 약관과 데이터 정책이 적용됩니다.

등록된 Windows와 그 프로필을 사용하는 MCP 클라이언트는 Mac 계정 권한으로 파일, 빌드, 터미널, 앱 및 화면을 제어할 수 있습니다. SSH 계정이 권한 경계이며 앱 승인은 운영체제 샌드박스가 아닙니다. 화면 기록·접근성·원격 로그인 등 필요한 Mac 권한은 사용자가 설정합니다. Mac의 실제 입력으로 정지된 제어는 명시적으로 재개해야 합니다.

로컬 데이터와 보관

- 연결 프로필: 기기 주소, 계정 이름, 호스트 공개 키, SSH 키 경로를 Windows 사용자 저장공간에 보관합니다. 개인 키는 로컬 SSH 키 파일에 있으며 화면·진단 내보내기에 포함하지 않습니다.

- 화면: 요청할 때 전송하며 자동 화면 갱신은 보이는 창에서만 작동합니다. Windows는 대상별 최신 프레임만 저장합니다. 정리 기준은 2분 및 전체 32 MiB입니다. 변경 작업의 실행 기록에는 이미지를 저장하지 않습니다.

- 작업 응답: Windows의 자동 정리 기준은 7일 및 응답 본문 전체 32 MiB입니다. 앱은 주기적으로, 독립 MCP는 요청 시 정리합니다. 프로세스가 종료되어 있거나 파일이 사용 중이면 다음 실행·정리까지 남을 수 있습니다.

- 작업 식별자·요청 해시·결과 상태: 취소되거나 통신이 끊긴 작업을 중복 실행하지 않도록 유지합니다. 이 작은 실행 기록은 자동 삭제하지 않으며 위 캐시 용량 제한에 포함되지 않습니다. 기록 보기에서 캐시 정리 및 색인 복구를 할 수 있습니다.

- 오류 진단: Windows의 마지막 처리되지 않은 오류 1개를 로컬에 최대 약 8 KiB의 텍스트로 덮어씁니다. 알려진 비밀값 형식은 마스킹하지만 파일 경로 등이 포함될 수 있습니다. 이 파일은 진단 내보내기나 자동 전송에 포함되지 않습니다.

- 프로젝트, 다운로드한 산출물, Mac의 빌드·명령 로그와 실행 기록은 자동 캐시 정리 대상이 아닙니다. 사용자가 관리하며, 삭제 전 실행 중인 작업 및 필요한 산출물을 확인해야 합니다. 앱 제거만으로 별도 프로젝트·SSH 키·Mac 작업 폴더가 지워지지는 않습니다.

외부 AI와 지원

앱 자체는 광고 SDK나 개발사로 전송하는 사용 추적 기능을 포함하지 않습니다. MCP를 AI 클라이언트에 연결하면 화면, 코드, 파일 내용, 명령 결과가 그 클라이언트에 전달될 수 있습니다. 이는 해당 클라이언트 및 모델 제공자의 데이터 정책과 사용자의 설정을 따릅니다. 민감한 프로젝트를 연결하기 전에 확인하세요.

‘진단 정보 저장’은 앱·OS 버전과 연결/오류 여부만 로컬 JSON 파일로 저장합니다. 주소, 계정 이름, 키, 토큰, 경로, 화면, 소스 및 원본 로그를 포함하지 않으며 자동 전송하지 않습니다. 사용자가 내용을 확인한 후 지원 요청에 직접 첨부할 수 있습니다. 별도로 보내는 화면·로그는 민감한 내용을 지운 뒤 제공하세요.

접근 해제와 문의

Mac의 등록 기기 목록에서 해당 Windows의 접근을 해제할 수 있습니다. 같은 공개 키의 앱 등록을 제거하고 앱 제어를 중지합니다. SSH 설정에 수동으로 중복 등록된 키가 있으면 이를 먼저 정리해야 하며, 이미 열린 외부 SSH 연결까지 종료하는 기능은 아닙니다. 유출이 의심되면 Mac 원격 로그인을 끄고 열린 SSH 세션과 계정을 확인하세요.

시작 앱 등록은 사용자가 켤 때만 설정합니다. Windows 트레이와 Mac 상태바에서 상태 확인·창 열기·종료가 가능합니다. 개인정보 및 제품 지원: support@slop-games.com.
